QUICK START
================================================================================

LOCAL DEVELOPMENT:
  1. Create MySQL database "learn_german"
  2. Visit http://localhost:8000/backend/setup
  3. Enter credentials, complete wizard
  4. Login to http://localhost:8000/backend/admin
  5. Delete backend/setup/install.php
  6. Connect React frontend to API

PRODUCTION (cPanel):
  1. Upload backend/ folder via FTP to public_html
  2. Create MySQL database in cPanel
  3. Visit https://yourdomain.com/backend/setup
  4. Complete wizard, save credentials
  5. Delete backend/setup/install.php
  6. Deploy React frontend to public_html
  7. Update React .env with API URL
  8. Change admin password

USER:
